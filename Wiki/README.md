# Wiki

This directory is the repository knowledge center.

Rules:
- Keep the wiki synchronized with repository changes.
- Prefer concise, factual pages that map to one canonical source.
- Update `index.md` when pages are added or their scope changes.
- Append new events to `log.md`; do not rewrite history.
